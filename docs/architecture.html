计划中(030 未落地) · 见 plans/030_hub_tasks_optimization.md
仍 await dispatcher.drain()：保留 hub 的 running 守卫；收益是后一房间的 job 行立即可见 + net/upload 与前一房间 CPU 重叠
② 多节点 hub 后处理 — 节点录制 → master 选优 → 合并/烧录/上传
